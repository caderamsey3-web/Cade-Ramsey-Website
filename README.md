# Cade Ramsey Personal Website

A static personal portfolio for job applications and professional networking.

## Pages

- `index.html` — Welcome, portrait, and profile and contact links.
- `experience.html` — Work experience, leadership, service, education, and skills.
- `interests.html` — Coding projects, ancient American civilizations, and distance running.
- `books.html` — Favorite books and a placeholder for another title.

## Preview locally

Keep the four HTML files in the same folder and open `index.html` in a browser. Each page includes its own styles and artwork; the welcome page embeds its portrait and Handshake logo. No build step or package installation is required.

## Hosting

The site is ready for static hosting from the repository root. `.nojekyll` allows the HTML files to be served directly by GitHub Pages once Pages is enabled for this repository.
